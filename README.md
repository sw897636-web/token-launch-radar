Token Launch Radar ranks 200 pre-token protocols by the implied value of a token they may one day issue — from TVL, seven-day growth, age with no token, and chain spread — and gives each one a farm plan with costs and times. The dashboard is a static page: sortable, filterable, with a detail view per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
